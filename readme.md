# Cypress Automated Tests – Heroes App

This project contains automated end-to-end tests developed using Cypress for the [Heroes App](https://github.com/wlsf82/serverest-frontend), originally created by [@wlsf82](https://github.com/wlsf82).

##  Important Note

>  This project is **not the original implementation** of the Heroes App.  
> I am responsible **only for the development of the test scenarios** using Cypress.  
>  
> You can find the original app and frontend in this repository:  
> 👉 [https://github.com/wlsf82/serverest-frontend](https://github.com/wlsf82/serverest-frontend)

##  How to Run Tests

1. Clone the repository:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2.Install dependencies:
```bash
npm install
```

3. Run Cypress Test Runner:
```bash
npx cypress run
```
