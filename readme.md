# Cypress Automated Tests – Heroes App

This project contains automated end-to-end tests developed using Cypress.

##  Important Note

>  This project is **not the original implementation** of the Heroes App.  
> I am responsible **only for the development of the test scenarios** using Cypress.  
 


##  How to Run Tests

1. Clone the repository:

```bash
git clone https://github.com/fernanda-amr/cypress-heroes-tests.git
```
2.Install dependencies:
```bash
npm install
```

3. Set up (databases and such):
```sh
npm run setup
```

4. To launch the app for development, run:
```sh
npm run dev
```

5. Open Cypress Test:
```bash
npx cypress open
```
